# Golden Temple

> Sacred yield farming sanctuary

## Features

- Temple staking
- Blessing rewards
- Festival events
- Community pool

## Tech Stack

- Frontend: HTML5, CSS3, JavaScript
- Blockchain: Solidity, Rust, Web3.js
- AI: MiMo V2 Flash, Claude Code

## Installation

```bash
git clone https://github.com/lemesbesti7/golden-temple.git
cd golden-temple
npm install
npm run dev
```
